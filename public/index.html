TRANSPARENT BY DESIGN

데이터 및 계산 기준

실제 가격·실적: Alpha Vantage. 가격은 일봉 종가이며 실시간 호가가 아닙니다. 회사가 직접 발표한 매출 가이던스 수정 이력은 연결되지 않았습니다. 없는 데이터는 N/A로 표시하고 점수에서 제외합니다.

01 / 출처와 시점

TIME_SERIES_DAILY_ADJUSTED에서 최대 260개 거래일의 OHLCV를 받아 분할 계수로 과거 가격·거래량을 최신 주식 단위에 맞춥니다. 배당은 조정하지 않습니다. 최신 가격은 마지막 수신 봉의 종가이며 각 종목의 기준일을 표시합니다. 4일 넘게 오래된 가격과 서로 다른 기준일의 가격은 순위에서 제외됩니다.

INCOME_STATEMENT의 최근 8개 분기 totalRevenue를 보고 통화 그대로 표시합니다. 서로 다른 보고 통화나 분기 누락이 있으면 비교 가능한 신호만 계산합니다. 분기말 날짜는 보고서 발표일과 다릅니다. 소급 백테스트용 시점 데이터는 아닙니다.

02 / 투명한 스윙 점수

50점에서 시작합니다. 종가 > EMA20이면 +8점, 아니면 −8점. EMA20 > EMA50이면 +7점, 아니면 −7점. 20세션 수익률 ÷ 12%를 −1~1로 제한해 10을 곱합니다. 확인된 상방·하방 돌파는 ±10점입니다.

매출 전년 동기 성장률 ÷ 25%를 −1~1로 제한해 5를 곱하고, 최근 3분기 연속 전분기 대비 성장하면 +3점, 아니면 −3점입니다. 매출 정보가 부족하면 전체 매출 항목은 제외됩니다. 회사 가이던스 ±7점 항목은 데이터가 없어 0점 기여(N/A)로 남깁니다. 가중치를 재조정하지 않으므로 전체 범위의 86%만 평가할 수 있습니다. 점수는 확률이나 검증된 수익 예측이 아닙니다.

03 / 삼각수렴과 거래량

최근 44개 봉에서 마지막 4개 봉을 제외한 구간을 탐색합니다. 양옆 2봉보다 높은 고점·낮은 저점 각각 최소 2개에 선형 회귀를 적용합니다. 저항선 하향, 지지선 상향, 폭 20% 초과 축소 시 수렴으로 분류합니다. 최신 종가가 선 밖에 있고 거래량이 이전 20세션 평균의 1.3배 이상이면 확인된 돌파로 분류합니다. 이는 최신 종가의 위치 확인이며 최초 돌파일을 찾는 백테스트는 아닙니다.

04 / 상승·하락 시나리오

14세션 True Range의 단순 평균을 ATR로 사용합니다. b=(점수−50)/50, k=√(거래일/20). 상승 목표=가격+ATR×k×(2.5+0.7b), 하락 목표=max(0.01, 가격−ATR×k×(2.5−0.7b)). 여력=(목표/현재가−1)×100. 이 계수들은 휴리스틱이며 백테스트로 최적화한 예측값이나 신뢰구간이 아닙니다.

05 / 애널리스트 전망과 회사 가이던스

전망 탭은 EARNINGS_ESTIMATES의 fiscal year 예상 매출을 별도로 보여줍니다. 애널리스트 컨센서스는 회사가 발표한 가이던스가 아닙니다. 서로 다른 회계연도의 예상 매출을 가이던스 상향 이력으로 해석하지 않으며 점수에도 사용하지 않습니다.

06 / 갱신·보유 내역·범위

화면을 열거나 새로고침 버튼을 누르면 데이터를 요청합니다. 가격은 서버에서 1시간, 매출·전망은 6시간 캐시합니다. 콜드 로드에는 시간이 걸릴 수 있습니다. 실패한 종목은 표시하고 샘플로 대체하지 않습니다. 동일 기준일에 가격과 매출이 모두 수신된 종목만 상대 순위에 포함하며, 데이터가 부족하면 후보가 10개보다 적을 수 있습니다. 상위·하위 후보는 서로 겹치지 않습니다.

보유 내역은 비공개로만 직접 저장합니다. Capital.com 계좌와 연결되지 않았으며 주문 기능도 없습니다. 평가는 USD 롱 기초자산 기준으로 레버리지·스프레드·금융비용·환율을 제외합니다. 과거 샘플 보유 내역은 실제 보유 내역으로 옮기지 않습니다. API 키는 서버 환경 변수에만 저장합니다.
